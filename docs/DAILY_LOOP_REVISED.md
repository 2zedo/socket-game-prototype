# 하루 루프 개정안

## 목적

이 문서는 새 세계관 기준의 하루 루프를 정리한다. 현재 구현된 DAY 1 MVP와 장기 해킹 의뢰 방향을 구분해, 다음 기획 작업의 기준으로 삼는다.

## 하루 루프

```text
아침 배급 확인
→ 의뢰 / 메시지 확인
→ 방 안 장치 탐색
→ 전력 배분과 장치 연결
→ 노트북으로 의뢰 작업 진입
→ 해킹/정보 작업 수행
→ 현실 방으로 복귀
→ 보상, 정보, 전력 소모 정산
→ 생존 기록
→ 잠들거나 02:00 한계 도달
```

## 현실 파트

방은 유이의 주거 공간이자 작업실이다.

플레이어는 제한된 전력 안에서 어떤 장치를 켜고 어떤 장치를 포기할지 선택한다. 전력은 생존, 작업, 정보 접근, 추가 수익과 연결된다.

현실 파트에서 중요한 것은 장치 자체가 아니라 선택의 압박이다.

- 노트북을 켜면 정보를 얻을 수 있지만 전력을 많이 쓴다.
- 통신 장치를 켜면 외부 신호나 공지를 확인할 수 있다.
- Phone은 상태 확인 장치지만 배터리가 없으면 정보를 볼 수 없다.
- 충전기는 Phone을 살리지만 그 시간 동안 전력을 소비한다.
- 선풍기나 조명은 생존감과 생활감을 주지만, 다른 작업 기회를 줄일 수 있다.

## 해킹 의뢰 파트

유이는 노트북을 통해 의뢰 작업을 수행한다.

장기 방향으로는 노트북 사용 시 별도 탑뷰 액션 해킹 미션에 진입한다. 첫 구현 목표는 해킹 액션 미션 1개다.

해킹 미션의 적은 인간이 아니다. 보안 프로그램, 방화벽 노드, 추적 드론, 감시 프로세스 같은 디지털 방어 시스템이 플레이어를 압박한다.

미션 성공 시 유이는 Grid Credit, 정보 조각, 스토리 플래그를 얻는다. 미션 실패 시 시간, 전력, 보상, 정보 획득에 손해가 생길 수 있다.

이번 문서에서 해킹 액션은 장기 구현 방향으로만 다룬다. 실제 해킹 액션 씬의 조작, 전투, 맵 구조, 보상 설계는 별도 문서에서 정의한다.

## 보상과 정산

하루의 결과는 단순 점수표가 아니라 유이의 생존 기록으로 정리한다.

정산 대상은 다음과 같다.

- 남은 전력
- 현재 켜거나 사용했던 장치
- 확인한 정보
- 얻은 보상 또는 놓친 보상
- Phone 배터리와 상태
- 다음 날에 영향을 줄 수 있는 작은 단서

Grid Credit과 전력 토큰은 장기 방향의 보상 축이다. 현재 DAY 1 MVP에는 아직 본격 경제 시스템이 들어가 있지 않다.

## 현재 구현

- 집 화면은 아직 기존 탑뷰 기반이다.
- 전력, 장치 연결, Phone, Result, `02:00` 종료, Test Mode는 이미 구현되어 있다.
- 노트북은 현재 방 안 상호작용 오브젝트다.
- 현재 DAY 1은 장치를 연결하고 켜고 끄며, 시간이 흐르는 동안 전력을 소비하고, Result에서 생존 기록을 보는 구조다.
- 해킹 액션 미션, Grid Credit, 의뢰 보상 정산은 아직 구현되어 있지 않다.

## 장기 방향

- 집 화면은 쿼터뷰 또는 아이소메트릭 느낌의 방으로 전환을 검토한다.
- 노트북을 통해 별도 탑뷰 액션 해킹 미션으로 진입한다.
- 해킹 미션 결과가 Grid Credit, 정보 플래그, Result 기록에 연결된다.
- 현실 방의 전력 선택과 해킹 미션의 위험이 서로 영향을 주도록 확장한다.

## 이번 단계에서 하지 않는 것

- 해킹 액션 씬 구현
- Grid Credit 경제 구현
- 의뢰 목록 UI 구현
- DAY 2+ 콘텐츠 구현
- 쿼터뷰 전환 구현
- 수면 버프, 피로도, 커피 같은 장기 상태 시스템 구현
