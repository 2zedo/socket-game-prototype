# 프로젝트 방향 개정 요약

## 목적

이 문서는 `CONCENT / 전력 부족의 시대`의 현재 구현 상태와 장기 방향을 한 번에 구분하기 위한 상위 기준 문서다.

Codex가 이후 작업을 시작할 때, 이미 구현된 시스템과 아직 문서상 장기 방향으로만 존재하는 아이디어를 섞지 않도록 돕는다.

## 프로젝트 한 줄 정의

`CONCENT`는 `THE GRID` 하층 구역의 정보 노동자 유이가 제한된 전력을 배분하며 생활하고, 노트북 의뢰 작업을 통해 Grid와 바깥 세계의 진실에 접근하는 게임이다.

## 현재 구현

현재 구현된 범위는 Godot DAY 1 MVP 중심이다.

- 현재 집 화면은 탑뷰 기반이다.
- DAY 1 MVP는 전력, 장치 연결, active 장치 소비, Phone UI, Result, `02:00` 자동 종료, Test Mode를 갖고 있다.
- 장치 데이터는 `godot/resources/devices/*.tres` Resource 기반이다.
- `SurvivalState.gd`는 전력, 연결 상태, active 상태, 슬롯 점유, Result 기록의 중심 상태를 관리한다.
- 멀티탭은 드래그 기반 adapter UI를 사용한다.
- 노트북은 현재 방 안 상호작용 오브젝트다.
- Phone UI는 현재 상태 확인 장치로 동작한다.
- Result 화면은 하루 생존 기록을 표시한다.
- 해킹 액션 모드는 아직 구현되어 있지 않다.
- 쿼터뷰 집 화면은 아직 구현되어 있지 않다.

## 장기 방향

아래 항목은 현재 구현이 아니라, 앞으로 검토할 장기 방향이다.

- 집 화면은 장기적으로 쿼터뷰 / 아이소메트릭 느낌의 방으로 전환을 검토한다.
- 쿼터뷰 전환은 바로 메인 씬을 바꾸지 않고, 별도 prototype scene에서 먼저 검증한다.
- 노트북은 장기적으로 별도 탑뷰 액션 해킹 미션으로 들어가는 입구가 된다.
- 해킹 미션 결과는 Grid Credit, 정보 플래그, Result 기록, 시간 / 전력 손실과 연결될 수 있다.
- 유이는 하층민 출신의 비공식 정보 노동자, 신호 해석가, 불법 로그 복원자다.
- 세계관은 `THE GRID`의 전력 배급, 정보 통제, 바깥 세계에 대한 의심을 중심으로 한다.
- DAY 1 이후에는 의뢰, 보상, 정보 플래그, 전력 토큰, Grid Credit 같은 장기 축을 검토한다.

## 현재 구현과 장기 방향 비교

| 항목 | 현재 구현 | 장기 방향 |
| --- | --- | --- |
| 집 화면 | 탑뷰 방 | 쿼터뷰 방 prototype 검토 |
| 노트북 | 상호작용 오브젝트 | 해킹 액션 미션 진입점 |
| 해킹 의뢰 | 미구현 | 별도 탑뷰 액션 모드 |
| 전력 | DAY 1 전력 소비 구현 | 해킹 결과 / 경제와 연결 |
| 장치 데이터 | `.tres` Resource 기반 | 더 많은 생활 전자기기와 의뢰 조건으로 확장 |
| Phone | 현재 상태 확인 UI | 의뢰 메시지와 결과 확인으로 확장 가능 |
| Result | 생존 기록 표시 | 해킹 성과와 정보 기록까지 확장 |
| 세계관 | 문서화됨 | DAY 2+와 의뢰를 통해 점진적으로 노출 |

## 구현 금지 목록

다음 항목은 별도 요청이나 prototype 계획 없이 Codex가 임의로 구현하지 않는다.

- 쿼터뷰 메인 전환
- 해킹 액션 미션 구현
- Grid Credit 경제 구현
- DAY 2+ 콘텐츠 구현
- 저장 / 로드
- 스킬트리
- 복잡한 분기 엔딩
- 장치 밸런스 대규모 변경
- 전력 토큰 / 구매 시스템
- 복수 해킹 미션
- 본격 의뢰 목록 UI

## 작업 기준

- 현재 구현을 수정할 때는 DAY 1 탑뷰 MVP가 깨지지 않는지 먼저 확인한다.
- 장기 방향 문서는 구현 명령이 아니라 기준 문서로 취급한다.
- 쿼터뷰와 해킹 액션은 바로 본 구현으로 들어가지 않는다.
- 새 기능은 먼저 작고 독립된 prototype으로 검증한다.
- 이미지 참고 자료는 분위기 참고용이며, 실제 UI나 에셋으로 복제하지 않는다.
