# 쿼터뷰 집 화면 방향

## 목적

이 문서는 `CONCENT / 전력 부족의 시대`의 집 화면을 장기적으로 쿼터뷰 / 아이소메트릭 느낌의 실내 공간으로 전환할 때 참고할 비주얼과 공간 방향을 정리한다.

현재 구현은 탑뷰 기반 방 화면이다. 이번 문서는 구현 지시가 아니라, 이후 prototype scene에서 검증할 장기 방향을 명확히 남기기 위한 기준 문서다.

## 핵심 방향

유이의 방은 단순 생활 공간이 아니라 THE GRID 하층 주거구에 있는 작은 개인 주거지이자, 하층 해커의 작업실이다. 방은 제한된 전력으로 하루를 버티는 공간이어야 하며, 동시에 불법 정보 의뢰를 처리하는 은밀한 작업 환경으로 읽혀야 한다.

장기적으로 집 화면은 쿼터뷰 / 아이소메트릭 느낌의 방을 목표로 한다. 완전한 3D 렌더풍보다는 사이버펑크 애니메이션풍, chill한 생활감, 약간의 귀여운 느낌이 섞인 방향이 적합하다.

방은 너무 깨끗한 미래형 공간이 아니어야 한다. 낡은 가구, 부족한 전력, 오래된 전자기기, 케이블, 메모, 부품 상자 등이 함께 보여야 하며, 유이가 하층민으로서 가진 생활의 압박이 공간 안에 남아 있어야 한다.

## 채택 콘티 기준

현재 채택한 쿼터뷰 방 콘티는 최종 게임 아트가 아니라 방향성 기준 이미지 / layout mood reference다. 앞으로 쿼터뷰 방을 제작할 때 아래 기준을 우선한다.

- 방은 THE GRID 하층 주거구의 1인실이다.
- 유이는 하층민 출신이지만 뒷세계 해커 / 정보 노동으로 어느 정도 벌이가 있다.
- 방은 빈민굴처럼 더럽고 처참하지 않고, 좁지만 정돈되어 있다.
- 생활 공간보다 작업 공간이 우선된다.
- 해커 장비와 전력 장비가 생활 공간을 점점 침식한 구조다.
- 방은 넓지 않지만 실제 게임 이동이 가능하도록 중앙 동선을 확보한다.
- 전체 분위기는 차갑고 어두운 THE GRID 외부와 따뜻한 실내 작업등이 대비되는 구조다.

즉, 유이의 방은 가난한 폐허가 아니라 제한된 자원 안에서 유지되는 하층 정보 노동자의 방이다. 낡고 압박감은 있지만, 유이가 일하고 버티기 위해 정리해 둔 공간이어야 한다.

## 조명과 분위기

집 화면의 핵심 대비는 따뜻한 실내 조명과 차가운 창밖 도시빛이다.

- 책상 주변은 따뜻한 조명으로 유이의 작업 공간을 강조한다.
- 창밖은 THE GRID 하층 도시의 차갑고 먼 불빛을 보여준다.
- 방 전체는 어둡고 조용해야 하지만, 플레이어가 이동 경로와 상호작용 대상을 읽을 수 있어야 한다.
- 전력 부족 세계관이 느껴지도록 빛은 넉넉하지 않고, 선택적으로 켜진 장치 주변에만 생명감이 있어야 한다.

## 공간 구성 요소

쿼터뷰 방에는 아래 요소가 핵심 오브젝트 후보로 들어간다.

- 침대
- 책상과 노트북
- 통신 장치 / 신호 장비
- Phone / 충전기
- 멀티탭 또는 전력 패널
- 냉장고
- 전자레인지
- 에어컨
- 조명
- 창문과 THE GRID 하층 도시 풍경
- 낡은 케이블, 부품 상자, 메모, 의뢰 기록

현재 구현에는 선풍기가 남아 있을 수 있다. 장기 방향에서는 방의 전력 압박과 하층 주거 환경을 더 명확히 보여주기 위해 선풍기를 에어컨으로 교체하는 방향도 검토한다. 단, 이는 장기 검토 항목이며 현재 구현을 즉시 변경한다는 의미는 아니다.

## 공간 배치 기준

채택 콘티 기준의 공간 배치는 아래처럼 잡는다. 좌표나 최종 배치 확정이 아니라, 쿼터뷰 아트와 prototype 검증 시 사용할 구역 기준이다.

### 좌측 / 좌하단

- 현관문
- 신발
- 외투 걸이
- 작은 수납
- 욕실 / 유닛배스는 문과 환기구 등으로만 암시

현관은 금속문, 도어락 / 카드리더, 신발, 외투 정도로 간결하게 처리한다. 현관을 과하게 장식하거나 이상한 네온 문구로 강조하지 않는다.

욕실 / 유닛배스는 직접 내부를 크게 보여주지 않는다. 작은 문, 환기구, 수건, 세면도구, 문 앞 타일 정도로 생활 구조를 암시한다.

### 좌측 / 중앙

- 작은 침대
- 침대 아래 수납
- 최소 생활 흔적

침대는 생활 공간이면서 수동 하루 종료 위치로 읽힐 수 있어야 한다. 단, 방의 중심은 침대가 아니라 작업 공간이다.

### 우측 / 창가

- 작업 책상
- 노트북
- NODE-17
- COMM
- Phone 충전 위치
- 스피커
- 메모보드
- 작업등

이 영역은 유이의 핵심 작업 공간이다. 창밖의 차가운 도시빛과 책상 주변의 따뜻한 작업등이 대비되어야 한다.

### 우측

- 냉장고
- 전자레인지
- 작은 싱크 / 조리대

생활 가전은 하층 1인실의 현실감을 주되, 멀티탭에 꽂는 소형 장치처럼 보이면 안 된다.

### 우하단

- 전력 패널
- UPS
- 멀티탭
- 신호 장비
- 케이블 정리함

전력 장비와 신호 장비는 작업 공간을 침식하는 형태로 둔다. 방은 정돈되어 있지만, 케이블과 장비가 유이의 생활 영역을 점점 밀어내는 느낌이 있어야 한다.

## 스피커 기준

스피커는 장식품이 아니라 해커 활동 관련 장치로 본다.

- 오디오 로그 재생
- 신호음 확인
- 경보음 확인
- 음성 데이터 분석
- 노이즈 속 방송이나 외부 신호 재생

따라서 스피커는 책상 주변 또는 작업 장비 구역에 배치한다. 단순 인테리어 소품처럼 다루지 않는다.

## 반드시 피할 것

- 화장실 / 욕실을 텍스트 라벨로 쓰지 않는다.
- 도면처럼 설명 라벨이 많은 이미지를 최종 방 디자인으로 삼지 않는다.
- 현관을 과하게 장식하거나 이상한 네온 문구로 강조하지 않는다.
- 식물은 많아야 작은 화분 1개 정도로 제한한다.
- 너무 가난한 폐허처럼 만들지 않는다.
- 너무 상류층스럽거나 넓고 고급스럽게 만들지 않는다.
- 앞쪽 벽을 높게 세워 쿼터뷰 시야를 막지 않는다.
- 하단 오브젝트의 축이 다른 방향으로 뒤집히지 않게 한다.
- 스피커를 장식품처럼 다루지 않는다.

## 비율과 게임 오브젝트 기준

캐릭터와 오브젝트의 비율은 방 안에서 함께 존재하는 것처럼 보여야 한다.

- 유이는 방 안을 실제로 걸어 다니는 크기감이어야 한다.
- 침대, 책상, 냉장고, 전자레인지, 에어컨은 배경 장식이 아니라 이동과 상호작용을 고려한 게임 오브젝트로 읽혀야 한다.
- 노트북, Phone, 충전기, 멀티탭은 작지만 상호작용 대상으로 식별 가능해야 한다.
- 가구와 전면 오브젝트는 캐릭터를 가릴 수 있으므로, 장기적으로 Y-sort나 전면 레이어 분리가 필요할 수 있다.

## Room Shell Layer 기준

실제 room art는 한 장짜리 배경으로 끝내지 않고, floor, back wall, side wall, window city view, foreground occluders, static lighting overlay 같은 shell layer로 분리하는 방향을 우선 검토한다.

Room shell layer의 파일명, `1920x1080` same-canvas 기준, z-index 초안, Godot 적용 순서는 `docs/QUARTERVIEW_ROOM_SHELL_LAYER_PLAN.md`에서 관리한다.

## 플레이 루프를 드러내는 방

쿼터뷰 방의 목표는 보기 좋은 배경 한 장이 아니다. 방 자체가 아래 루프를 자연스럽게 드러내야 한다.

```text
방 안을 걷는다
→ 장치를 확인한다
→ 전력을 배분한다
→ 노트북으로 의뢰 작업에 들어간다
→ 결과를 기록한다
→ 하루를 마친다
```

따라서 방의 배치는 플레이어가 무엇을 할 수 있는지 읽기 쉬워야 한다. 장식 밀도는 필요하지만, 전력 관리와 의뢰 작업의 주요 오브젝트가 묻히면 안 된다.

## 이미지 참고 정책

첨부된 쿼터뷰 방 이미지는 reference only로 취급한다. 채택 콘티는 아래 요소를 참고하기 위한 방향성 기준 이미지 / layout mood reference다.

- 방의 분위기
- 하층 해커 작업실 느낌
- 따뜻한 실내 조명과 차가운 도시 야경의 대비
- 쿼터뷰 공간감
- 전자기기와 생활 오브젝트가 섞인 밀도감
- 좁지만 정돈된 하층 1인실
- 생활 공간보다 작업 공간이 우선되는 배치
- 중앙 이동 동선 확보
- 현관 / 욕실 / 주방이 배경 구조로 암시되는 방식

첨부 이미지에서 아래 요소를 그대로 가져오지 않는다.

- 이미지 안의 UI 문구
- 정확한 오브젝트 위치
- 텍스트 디자인
- 캐릭터 외형 세부
- 좌표나 방 크기
- 실제 구현용 에셋
- 콘티에 있는 문구나 장식 텍스트
- 도면식 설명 라벨

텍스트 기획 문서와 현재 프로젝트 구조가 source of truth이며, 이미지는 장기 방향을 설명하기 위한 참고 자료로만 사용한다.

## 현재 구현과의 구분

- 현재 구현: 탑뷰 기반 집 화면
- 장기 방향: 쿼터뷰 / 아이소메트릭 느낌의 집 화면 검토
- 이번 작업: 방향 문서화
- 이번 작업에서 구현하지 않음: Godot scene 변경, 코드 변경, 에셋 교체, 쿼터뷰 prototype scene 생성
