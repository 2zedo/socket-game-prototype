# 방 오브젝트 설계 방향

## 목적

이 문서는 유이의 방에 추가될 생활 / 해킹 오브젝트의 장기 설계 방향을 정리한다.

이번 문서는 구현 지시가 아니라, 앞으로 장치를 추가하거나 교체할 때 어떤 장치가 어떤 루프에 연결되는지 혼동하지 않기 위한 기준 문서다. 현재 DAY 1 장치 Resource 값, 기존 Fan / Light 구현, 멀티탭 UI, 전력 밸런스는 이 문서 작성으로 변경하지 않는다.

## 핵심 방향

유이의 방은 하층 주거 공간이자 해킹 작업실이다. 방 안 오브젝트는 단순 장식이 아니라, 아래 네 축 중 하나와 연결되어야 한다.

```text
전기 = 생존
전기 = 노동
전기 = 정보 접근
전기 = 계급 차이
```

장치는 전력을 쓰는 물건이라는 공통점을 갖지만, 모두 같은 방식으로 관리하면 방의 의미가 흐려진다. 따라서 기본 설비, 생활 유지 장치, 해킹 작업 장치, 충전 / 저장 장치를 구분해 설계한다.

## 장치 분류

### 기본 설비

기본 설비는 플레이어가 매번 멀티탭에 꽂아 관리하는 장치가 아니라, 방 자체에 포함된 설비로 취급한다.

#### 형광등

- 책상 위 램프는 장기적으로 제거한다.
- 방 조명은 형광등 중심으로 간다.
- 저녁이 되면 자연스럽게 켜지는 기본 설비처럼 취급한다.
- 형광등 전력은 플레이어가 매번 직접 지불하는 전력이 아니라, 기본 배급 전력에서 관리비 / 공동관리비처럼 이미 선차감된 느낌으로 처리한다.
- 조명은 분위기와 시간 연출용이며, 초반 핵심 전력 선택 압박의 중심이 아니다.

현재 구현에는 Light / Lamp가 멀티탭 연결 장치처럼 남아 있을 수 있다. 이 문서는 장기 방향을 정리하는 것이며, 현재 Resource나 코드 값을 변경하지 않는다.

### 생활 유지 장치

생활 유지 장치는 유이의 생활감과 생존 압박을 만드는 장치다.

#### 냉장고

- 식량 보존과 장기 생활 유지에 연결된다.
- 기본적으로 켜져 있거나, 꺼두면 다음 날 식량 / 컨디션 / 비용 리스크가 생기는 유지 장치로 검토한다.
- 멀티탭에 꽂는 소형 장치보다는 벽 전원 또는 전용 회로가 자연스럽다.

#### 전자레인지

- 식사와 컨디션 회복에 연결된다.
- 지속 소비 장치가 아니라 짧은 시간에 강한 전력을 쓰는 순간 소비 장치로 검토한다.
- 사용하면 즉시 전력을 쓰고, 짧은 게임 시간이 지나가는 방식이 어울린다.

#### 에어컨

- THE GRID 하층 주거구의 열기, 작업 집중력, 피로감을 관리하는 고전력 지속 소비 장치다.
- 현재 구현에는 Fan이 남아 있을 수 있다.
- 장기 방향에서는 Fan을 에어컨으로 교체할지 검토한다.
- 이 교체는 현재 구현 변경이 아니라, 쿼터뷰 방과 생활 장치 확장 단계에서 판단할 장기 설계 항목이다.

### 해킹 작업 핵심 장치

해킹 작업 핵심 장치는 유이가 의뢰를 처리하고 THE GRID의 정보를 추적하는 장치다.

#### 노트북

- 해킹 의뢰 진입, 로그 복원, 데이터 분석의 중심이다.
- 현재 구현에서는 방 안 상호작용 오브젝트다.
- 장기 방향에서는 노트북을 통해 별도 탑뷰 액션 해킹 미션으로 진입한다.
- 전력 소비는 노동 시간과 정보 접근 비용을 직접 보여주는 장치여야 한다.

#### 통신 장치

- 폐쇄망, 외부 신호, 관리 방송, 의뢰 신호 수신에 연결된다.
- 노트북과 함께 쓰면 정보 획득 또는 해킹 미션 조건에 영향을 줄 수 있다.
- 현재 DAY 1에서는 구현된 장치로 남기되, 장기적으로는 외부 세계와 Grid 검열 흔적을 드러내는 역할을 강화한다.

#### NODE-17

- 메인 미스터리 장치다.
- Grid 외부 또는 관리망 바깥 신호와 연결되는 핵심 오브젝트로 검토한다.
- 단순한 추가 전자기기가 아니라, 스토리 플래그와 외부 세계 의심을 키우는 장치여야 한다.
- 전력 유지 여부가 신호 보존, 단서 획득, 스토리 리스크와 연결될 수 있다.

### 해킹 보조 장치

해킹 보조 장치는 해킹 미션과 정보 수집을 보조한다. 핵심 장치보다 선택 압박은 낮을 수 있지만, 특정 미션 조건이나 정보 품질에 영향을 준다.

#### 신호 증폭기

- 통신 품질, 해킹 미션 조건, 외부 신호 수신률을 개선하는 장치다.
- 켜면 전력을 쓰지만, 의뢰 성공 조건이나 정보 획득 가능성이 좋아지는 방향으로 검토한다.
- 통신 장치와 함께 쓰면 의미가 커지는 보조 장치가 될 수 있다.

#### 스피커

- 음성 로그, 관리 방송, 노이즈 속 신호 재생, 분위기 연출용 장치다.
- 낮은 전력 소비의 정보 / 연출 장치로 검토한다.
- 해킹 액션보다는 방 안 정보 해석과 세계관 전달에 어울린다.

#### 장기 해킹 장비 후보

아래 장치는 아직 확정하지 않는다. 장기 해킹 장비 후보로만 둔다.

- CCTV 수신기
- 불법 라우터
- 외장 저장장치 / 데이터 리더
- 납땜 인두
- 소형 서버 / NAS
- 냉각 패드

### 충전 / 저장 장치

충전 / 저장 장치는 전력을 다른 자원으로 바꾸거나 비상 상황에 대비하게 만든다.

#### Phone 충전기

- Phone 배터리를 유지한다.
- 의뢰 확인, 상태 확인, 메시지 수신과 연결된다.
- 현재 구현에서는 Phone UI가 상태 확인 장치이므로, 충전기는 정보 접근 유지 비용을 보여준다.

#### 보조배터리 / UPS

- 남는 전력을 저장하거나, 해킹 작업 중 갑작스러운 전력 부족을 막는 장치다.
- 오늘 전력을 바로 쓸지, 나중을 위해 저장할지 선택하게 만든다.
- 해킹 미션 실패나 장시간 작업 중 전력 끊김 리스크를 줄이는 장기 장치로 검토한다.

## 전력 처리 방식 제안

아래 표는 추천 방향이다. 실제 수치나 Resource 값은 이번 문서에서 구현하지 않는다.

| 타입 | 예시 | 처리 방향 |
| --- | --- | --- |
| 기본 설비 | 형광등 | 기본 배급에서 선차감된 관리 전력 느낌 |
| 지속 소비 | 노트북, 통신 장치, 에어컨, NODE-17, 신호 증폭기 | 켜져 있는 동안 시간당 소비 |
| 순간 소비 | 전자레인지 | 사용 시 즉시 전력 소비 + 짧은 시간 경과 |
| 유지 장치 | 냉장고, NODE-17 | 꺼두면 식량 / 신호 / 스토리 리스크 |
| 충전 / 저장 | Phone 충전기, UPS | 전력을 배터리 / 저장량으로 전환 |
| 해킹 보조 | 신호 증폭기, 스피커, 통신 장치 | 미션 조건 / 정보 획득에 영향 |

## 멀티탭과 벽 전원 구분

모든 장치를 멀티탭에 넣지 않는다. 멀티탭은 유이가 직접 꽂고 빼며 선택 압박을 느끼는 소형 작업 장치 중심으로 사용한다.

### 멀티탭에 어울리는 장치

```text
노트북
통신 장치
Phone 충전기
NODE-17
신호 증폭기
스피커
보조배터리 / UPS 충전기
```

### 벽 전원 / 전용 회로가 자연스러운 장치

```text
냉장고
전자레인지
에어컨
형광등
```

이 구분은 장기 설계 방향이다. 현재 DAY 1 구현의 Light / Fan / 멀티탭 구조를 이번 문서로 변경하지 않는다.

생활 유지 장치의 장기 행동과 전력 모델은 `LivingDeviceDefinition` Resource class로 분리할 준비를 시작했다. 이 구조는 냉장고, 전자레인지, 에어컨, 형광등, UPS 같은 후보를 문서화하기 위한 기반이며, 이번 단계에서 실제 장치 값이나 gameplay wiring은 추가하지 않는다.

Fridge, microwave, aircon, fluorescent light, and UPS visual bodies should be managed separately from furniture and work-device atlases. Future appliance body region mapping criteria are documented in `docs/QV_APPLIANCES_ATLAS_REGION_MAPPING.md`.

Laptop, phone, NODE-17, communication device, speaker / audio analyzer, and signal booster visual bodies should be managed separately from furniture and appliance atlases. Future work-device body region mapping criteria are documented in `docs/QV_WORK_DEVICES_ATLAS_REGION_MAPPING.md`.

## 추천 임시 수치

아래 값은 플레이테스트 전 문서상 후보값이다. 이번 작업에서 `godot/resources/devices/*.tres`나 기존 밸런스 값을 수정하지 않는다.

```text
노트북: 기존 3.0 / game hour 유지
통신 장치: 기존 2.0 / game hour 유지
Phone 충전기: 기존 1.0 / game hour 유지
에어컨: 2.0 / game hour 후보
냉장고: 0.5 / game hour 후보
NODE-17: 1.2 / game hour 후보
신호 증폭기: 1.0 / game hour 후보
스피커: 0.3 / game hour 후보
UPS 충전: 1.0 / game hour, 최대 저장 2~3 units 후보
전자레인지: 즉시 0.7 소비 + 10~20분 경과 후보
형광등: 직접 소비 없음, 기본 배급 선차감 처리 후보
```

이 수치는 확정 밸런스가 아니다. 실제 구현 전에는 DAY 길이, active 소비 체감, Phone 배터리, 해킹 미션 시간 비용과 함께 다시 조정한다.

## 현재 구현

- DAY 1 장치 Resource는 기존 상태를 유지한다.
- Fan은 현재 구현에 남아 있을 수 있다.
- Light / Lamp 관련 구현도 아직 최종 설계 전 상태다.
- 노트북, 통신 장치, Phone 충전기, Fan, Light / Lamp는 현재 DAY 1 MVP 장치 흐름에 포함되어 있다.
- 냉장고, 전자레인지, 에어컨, NODE-17, 신호 증폭기, UPS, 스피커는 아직 본격 구현하지 않았다.

## 장기 방향

- Fan은 에어컨으로 교체를 검토한다.
- 책상 램프는 제거하고 형광등 중심으로 전환한다.
- 생활 장치와 해킹 장치를 분리해 방의 역할을 명확히 한다.
- 해킹 장비는 노트북 의뢰와 장기 해킹 액션 모드에 연결한다.
- 냉장고, 전자레인지, 에어컨 같은 생활 장치는 단순 장식이 아니라 생존 압박과 하루 정산에 연결한다.
- NODE-17은 외부 신호와 THE GRID 미스터리를 묶는 장기 핵심 오브젝트로 검토한다.

## 이번 단계에서 하지 않는 것

- DAY 1 Resource 값 수정
- Fan 제거 또는 에어컨 구현
- 냉장고 / 전자레인지 / NODE-17 / 신호 증폭기 / UPS / 스피커 구현
- 멀티탭 UI 변경
- 해킹 액션 구현
- 장치 밸런스 조정
- 새 에셋 추가
